Hey! I'm **Abdulhakim**, a Computer Science student interested in understanding how software works beneath the surface.

I'm exploring the world of reverse engineering, malware analysis, assembly, and binary exploitation. I enjoy taking unfamiliar binaries apart, tracing their logic, and learning how to recognize suspicious behavior.

- 🔬 Learning static and dynamic malware analysis
- 🧩 Practicing reverse engineering with IDA, Ghidra, and GDB
- 💻 Exploring C, Python, x86/x64 assembly, and Linux internals
- 🚩 Solving beginner-friendly CTF challenges, especially reversing and pwn
- 🛡️ Building knowledge of defensive security and malware detection
- 📚 Improving through hands-on labs, experiments, and write-ups

> My goal: understand what happens inside a binary, not just what happens when you run it.
